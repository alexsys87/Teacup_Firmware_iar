# Тестирование Renode в Windows

Из папки `test` в командной строке Windows:

```bat
run-renode.cmd
run-renode.cmd -Chip F401
run-renode.cmd -Chip F411
run-renode.cmd -SelfTest
run-renode.cmd -Suite All -List
run-renode.cmd -Suite All
```

Лаунчер без прав администратора скачивает и кеширует переносимые Renode,
Python, GCC Arm и make. По умолчанию запускаются UART, USB и маршрутизация
USB для обоих чипов. `-Suite All` добавляет расширенные наборы для F401;
это не Linux-зависимые `run_menu.py`, `run_sdcard.py` и `run_printcore.py`.
Подробные ограничения и параметры приведены в основном README.

Короткая диагностика (не заменяет полный набор):

```bat
run-renode.cmd -Chip F401 -Part basic,proto -TimeoutSeconds 300
```

Это basic/proto для UART и USB, а также полный набор маршрутизации USB.
Логи и сгенерированные скрипты находятся в `test/results/<набор>/`.
Таймаут возвращает код 124; ошибки монитора Renode — код 1. Проверки
прошивки не отключаются и не заменяются успешным завершением эмулятора.

## Совместимость моделей с Renode 1.17.0

Во всех шести описаниях платформ F401/F411 (обычное, DMA и DMA+flash)
I2C использует тип `I2C.STM32F1_I2C`. Именно этот тип применяется к STM32F4
в [исходной платформе Renode v1.17.0](https://github.com/renode/renode/blob/v1.17.0/platforms/cpus/stm32f4.repl).
Прежнее имя `I2C.STM32F4_I2C` отсутствует в переносимой версии и вызывало
`Error E04: Could not resolve type` ещё до выполнения прошивки. Изменено
только имя типа: адреса I2C, подключения `EventInterrupt`/`ErrorInterrupt`,
прошивка и её проверки сохранены. Это совместимость описания платформы,
а не подтверждение работы аппаратного I2C или ослабление тестов.

Путь запуска `.resc` явно заключён в кавычки на уровне монитора Renode,
поэтому поддерживаются папки с пробелами. Стандартный ввод остаётся
открытым до завершения эмуляции. Лаунчер также следит за конкретными
ошибками загрузки/разбора монитора и останавливает процесс, не ожидая
30 минут интерактивного приглашения. Обычный ответ прошивки `Error:`
(например, срабатывание температурной защиты) не считается такой ошибкой.
